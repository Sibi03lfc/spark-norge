# SparkNorge – PWA

## Filer
- `index.html` – selve appen
- `manifest.json` – app-manifest (navn, ikoner, farger)
- `sw.js` – service worker (offline-støtte, caching)
- `icon-192.png` – app-ikon (Android)
- `icon-512.png` – app-ikon (stor)

## Installer på telefon

### Alternativ A: GitHub Pages (gratis, anbefalt)
1. Opprett gratis konto på github.com
2. Lag nytt repo: "sparknorge"
3. Last opp alle filene i denne mappen
4. Gå til Settings → Pages → Branch: main → Save
5. Din app er live på: https://DITT-NAVN.github.io/sparknorge
6. Åpne linken på telefonen og trykk "Legg til på hjemskjerm"

### Alternativ B: Cloudflare Pages (gratis)
1. Gå til pages.cloudflare.com
2. "Create a project" → "Direct upload"
3. Dra alle filene inn
4. Appen er live med en gang

### Installer på iPhone (Safari)
1. Åpne appen i Safari
2. Trykk Del-knappen (□↑)
3. Velg "Legg til på hjemskjerm"
4. Trykk "Legg til"

### Installer på Android (Chrome)
1. Åpne appen i Chrome
2. Trykk ⋮ (meny) → "Legg til på startskjermen"
   ELLER banneret som dukker opp nederst
3. Trykk "Installer"
